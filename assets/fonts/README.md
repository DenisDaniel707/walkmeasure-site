# Fonts

Self-hosted so the site makes no requests to third parties (the privacy pages say so).
Both are variable fonts from Google Fonts, under the SIL Open Font License 1.1
(https://openfontlicense.org), split into the `latin` and `latin-ext` subsets
(latin-ext carries the Romanian ă, â, î, ș, ț).

- Bricolage Grotesque (display: headings, prices, numbers), weight 400–800, width 75–100 %
- Instrument Sans (text), weight 400–700
